# docs/design/motion/fold-loader

This folder holds the folding-paper loading animation used by the website.
The animation code is in [apps/web](../../../../apps/web/src/app/ui/fold-loader).
The `fold-loop.webp` file shows the animation.
Run `npm run visual:fold-loader` to capture the current folding and writing views.
See [the full test record](README.robot.md) for details.
