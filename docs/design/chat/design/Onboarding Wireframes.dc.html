12 New conversation — kill the modal, derive the mode from the address

Slack's move: New opens a draft, not a dialog — you address it, then type. The mode question answers itself from WHO is in the To line: your agent → Agent session, a person → Direct, several → Group. The "choose once, cannot change" rule survives — it locks at first send, shown as a quiet strip, never asked as a form. And because agent chat is the dominant workflow, it gets a zero-friction fast path that skips even the To line.

10 Agent threads — @agent in a group chat spawns a governed child

Slack's thread affordance, OpenCrane's rules: an authorized @agent mention creates an Agent thread (mode: agent session, immutably linked to its root message) and its first run. The parent shows only a compact summary; the child opens as a full workspace view with a breadcrumb — never a side panel. Everything inside the child is run-backed, one foreground run at a time. Runtime subagents are a different thing and never appear here.
