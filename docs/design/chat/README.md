# docs/design/chat

The first design for sign-in, onboarding and the chat workspace.
The live chat is in [apps/web](../../../apps/web/README.md), and some designed features
are not built yet.
The `design/` folder holds screen references and `wireframes/` holds early sketches.
The `comparison/` folder holds pictures made by `npm run visual:chat`.
The `live/` folder holds screenshots saved by scripted test runs on the
[dev stack](../../../GLOSSARY.md#dev-stack).
Other files record implementation notes, visual fixes, licences and past checks.
See [the full design notes](README.robot.md) for details.
