# docs/design index

For people, read [README.md](README.md) first.

The designs are reference material. They do not prove that screens work. Full-size files
for the newer handoff are held outside the repository; ask the design owner for them.
The `chat`, `org-admin` and `motion/fold-loader` folders include local visual checks.

`claude-design-briefs.md` and `handoff-v2/PLAN.md` are planning records for maintainers.
They contain detailed prompts and build notes that are not user guides.
