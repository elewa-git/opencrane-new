# docs/design/org-admin

The first design for organisation settings, including models, tool servers, people and
groups. The live settings pages are in [apps/web](../../../apps/web/README.md).
The newer design changed the navigation and removed the skills and workflows page.
The design covers overview, models, integrations, people, groups and change history.
Run `npm run visual:org-admin` to save comparison pictures.
See [the full design notes](README.robot.md) for details.
