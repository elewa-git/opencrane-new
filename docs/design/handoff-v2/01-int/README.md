# Integrations and my tools

This design shows how people connect
[tool servers](../../../../GLOSSARY.md#mcp-server-tool-server) and choose which tools
they may use.
The integrations screen is built in `apps/web`. Personal tool settings are not built yet;
that page only says so.
These pictures show intended states, not proof that every state works.
See the [list of newer designs](../README.md) and [full design notes](README.robot.md).
