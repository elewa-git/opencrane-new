# Images and file links in assistant chat

These screenshots use the production web build and an intercepted API. The example
shows an uploaded image, an assistant SVG and a reply link to that file. A link to
an unavailable file shows a plain note. The SVG preview uses an image element and
contains a script that must remain inert. This is not a fresh-install journey.
