# Checking a company account for one routine call

The private models library can match a saved routine run to an explicitly chosen,
verified company account. It checks that the current published tool remains a free
Allow call, then records one audit. It reads no private account material.

The server has no caller for this path. A saved company connection alone does not
verify the upstream account. The recording tests use synthetic verification and
cannot qualify a live company call.

The [contract and own checks](README.robot.md) give the precise limits.
