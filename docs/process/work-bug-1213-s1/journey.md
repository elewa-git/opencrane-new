# Invitation acceptance after reinstalling

**NOT RUN.** The packaged browser check awaits both CI image approvals for the
product commit.

The check uses slot 1 and two browser windows at 1280 px and 390 px. Each keeps its
sign-in cookie while the package is reinstalled at the same address. The person
signs in again and accepts a new invitation. The check also looks for the
sign-in prompt when the session expires while the invitation is open.
