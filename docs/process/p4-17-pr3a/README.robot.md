# Nightly memory preflight

The dispatcher sends only a saved scope and night identifier to the loopback
decision process. The server checks the original claim against later binding
and content changes, overlap, the 15-minute window and managed route mode.
One safe result is saved on the scope stream. Duplicate delivery, restart and
lost append replies read that result. Refusal status contains no memory text.

Root allowance, current grants, provider key evidence, price, budget admission,
private turn and all dispatch remain out of this first slice. They cannot be
inferred from a preflight result. Live qualification and paid use are NOT RUN.
