# Stopping a saved routine run

A saved Stop applies to one routine run and its spending allowance. The bridge interrupts
only that run's private turn. It also cancels a waiting start acknowledgement before
credentials can leave the server. Other work on the same computer can continue.

The models process checks saved native closure and budget Stop before releasing the
routine's occupied slot. A timeout or lost connection cannot prove completion.
Restart repeats the checks from saved records without sending the input again.
Automatic routine execution remains unavailable.

The [contract and own checks](README.robot.md) record the test scope and remaining work.
