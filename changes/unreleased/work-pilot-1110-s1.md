The local Helm package can use a provider connected in Settings with
`models.mode: provider`. It keeps provider keys on private persistent storage,
gives the server write access and models read access, skips the stand-in and
includes HTTPS trust for real replies. The default install keeps its existing
stand-in behaviour.

Keep connected provider keys private after Pod recreation. Admins can select the
chat default and switch on from Settings. A restricted, separate free provider
supports packaged qualification with wrong-key refusal and ordinary key custody.
Provider journey failures name the step and expected condition without copying
credentials or private paths into the public result.
Fresh owner bootstrap finishes applying ownership permissions before opening the
installation for checked owner commands.
Dispatch reuses its reserved database connection when reactions fill the pool,
including the queue-setting reads needed to save new jobs.
Follow automatic provider setup advancement when its status button disappears
during a click.
