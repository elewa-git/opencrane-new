Admins can mark a reviewed tool server as needing a personal key and choose its
read-only account check. Members can save and verify their own key in My tools,
select it, and use the server's tools in chat. Members without a verified key see a
link to connect one. Catalogue checks and replay retain the admin's choice.
Encoded key echoes are refused before saving account details. Refusal replies carry
fixed reasons, and private failure logs classify causes without copying credentials.

The demo tool server has an optional credential-checked mode with two caller-supplied
synthetic accounts and a read-only identity tool. Its default mode is unchanged.

Attachment retry and removal buttons keep a 44 px touch target on phones.
