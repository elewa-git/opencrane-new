Email invitations can be accepted by a recently signed-in account with the matching
verified email in the silo's organisation. Acceptance records the account, refuses
an account already active in the silo and lets only one account accept each invitation.
Repeating the same command recovers a saved join after a lost reply.

Concurrent invitations cannot admit the same account twice. Acceptance looks up
account records and recent events, so older unrelated member history no longer
stops new people from joining.
