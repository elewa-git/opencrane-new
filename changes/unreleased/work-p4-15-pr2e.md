A turn receives no renewed pass when a loaded memory fact was corrected, forgotten or expired, a dependency became invalid, or its requester or assistant lost memory access. The server checks again after signing, before returning the pass. Access revoked during the final memory read also prevents renewal.

Each renewed pass checks memory up to the last position read from each memory stream. A correction or forget saved during the final access check may allow that pass, but prevents the next renewal or decision confirmation.
