Operators can switch the demo to the tailnet pilot for testing with disposable
data. The checked switch saves the old demo route so it can be restored.
The rehearsal result is scheduled backup FAIL at verify, zero completed sets,
restore NOT RUN. Real data waits for slice 2 to pass backup and restore.
The packaged server keeps the pilot sign-in credential in its own Secret.
Invited people can open their link, sign in again if needed and retry a
lost acceptance reply without sending a second command.
Owners can still open the member list and invite people when only the event
position for the directory totals is unavailable.
