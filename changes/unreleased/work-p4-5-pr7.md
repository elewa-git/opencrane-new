# Group participant controls

People can review the current participants in a group conversation. The creator can add
or remove other people, while everyone else can leave. The creator stays in the chat. A
person removed from the company is shown as removed. If a change reply is lost, the page
checks the same command status without sending it again. When access ends, protected
conversation details and cached socket messages are cleared, and late replies stay
hidden. Participant changes update the open list as they arrive. A socket resync reloads
the current participant list and conversation names. Workspace links keep an uncertain
change on screen so its status can still be checked. Search follows every server result
page, and the phone picker keeps keyboard focus inside its dialog.
