- Personal assistants can receive initial memory once on a fresh private turn after deployment qualification, with checks during signing and no resend after a lost acknowledgement. Explicit memory-free work receives no history, memory block or offered tools. Native memory tools and private reply delivery remain unavailable.
- Already started turns can renew their passes without preparing initial memory again. Numbered starts require saved initial-load evidence, so a later report cannot bypass refused preparation. Access and loaded-memory checks still run before and after signing.
- Initial memory delivery reuses saved access history within each check, reducing repeated reads that could exhaust the two-second limit before a native turn starts. Current permissions, changed access and all memory checks still apply.
