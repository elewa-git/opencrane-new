# Private tool-instance records

Private tool instances have checked identities, run records and owner stop requests.
Owners can read safe status and the result of their original recorded change through
the shared library. Rebuilding the read table starts no process and releases no credentials.
Wake remains refused. HTTP routes and live workers are still to come.
The startup access version is recorded as `startupAccessGeneration`, a positive integer
with no secret value. Event security checks apply without a name exception.
Malformed instance data is refused without throwing from the event parser.
Concurrent retries with a changed stop payload are refused before returning a receipt.
